# Oropod's Homebrew tap

Command-line tools from [Oropod](https://oropod.com), for macOS.

```sh
brew install oropod/tap/<tool>
```

## Tools

| Tool | What it does | Install |
| --- | --- | --- |
| `orostore` | Manage your organisation's Oropod Storage: crew, Seats and managers | `brew install oropod/tap/orostore` |

Each formula installs a prebuilt binary attached to a release of this repository, tagged `<tool>-v<version>`. Upgrade with `brew upgrade`.
